# 📝 Simple To-Do List App (v2)

A **powerful and modern** To-Do List application built with **React**, now featuring a **backend** with **Supabase** for persistent task storage. This version introduces a **new UI**, **dark mode toggle**, and improved **state management** using `useReducer` + Context API. Data fetching and updates are now handled efficiently with **React Query**.

## 🚀 Features

- ✅ **Persistent Storage**: Tasks are now saved in **Supabase**, allowing users to keep their data across sessions.
- 🎨 **New UI & Dark Mode**: Fully redesigned interface with **styled-components** and a **light/dark mode toggle**.
- 📱 **Fully Responsive**: Optimized for mobile, tablet, and desktop screens.
- ⚡ **State Management Upgrade**: Now using **`useReducer` + Context API** for better scalability.
- 🔄 **Optimized Data Fetching**: Uses **React Query** for smooth real-time updates.
- 🗑️ **Task Management**:
  - Add tasks
  - Mark tasks as completed
  - Remove individual tasks
  - Bulk remove completed tasks

## 🛠️ Tech Stack

- **React** (Functional Components + Hooks)
- **useReducer + Context API** (State Management)
- **React Query** (Data Fetching & Updates)
- **Supabase** (Backend for storing tasks)
- **Styled-Components** (Styling)

## 🏗️ Getting Started

```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
npm install
npm run dev
```
