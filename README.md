# 📝 Simple To-Do List App

A **minimal and efficient** To-Do List application built with **React**, leveraging `useReducer` for state management and **Tailwind CSS** for styling. The app is **fully responsive**, ensuring a smooth user experience across all devices.

## 🚀 Features

- ✅ **State Management**: Uses `useReducer` for handling tasks efficiently.  
- 🎨 **Modern UI**: Styled with **Tailwind CSS** for a sleek and responsive design.  
- 📱 **Fully Responsive**: Works seamlessly on mobile, tablet, and desktop screens.  
- 🗑️ **Task Management**:  
  - Add tasks  
  - Mark tasks as completed  
  - Remove individual tasks  
  - Bulk remove completed tasks  

## 🛠️ Tech Stack

- **React** (Functional Components + Hooks)
- **useReducer** (State Management)
- **Tailwind CSS** (Styling)
- **ESLint** (Code Quality)


## 🏗️ Getting Started
  
```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
npm install
npm run dev
```

## 🎮 Usage Guide

- **Add a Task**: Type in the input field and click "Add".
- **Mark Task as Completed**: Click the checkbox to toggle task completion.
- **Remove a Task**: Click the ❌ button next to a task to delete it.
- **Remove All Completed Tasks**: Click the "Remove" button to clear all completed tasks.
